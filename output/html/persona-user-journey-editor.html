Sẵn sàng chỉnh sửa

Bấm vào nội dung để sửa.

Bản nháp lưu trong trình duyệt khi được hỗ trợ. Dùng Lưu bản HTML để giữ file hoặc chuyển sang máy khác.

Sau khi sửa, lưu HTML rồi nhập bản đó vào repo để tạo lại Markdown và PDF.

Khôi phục nội dung khi mở file?

Thao tác này thay toàn bộ nội dung bằng bản gốc nhúng trong file HTML đang mở. Hãy lưu bản HTML hoặc xuất JSON trước nếu muốn giữ thay đổi.
