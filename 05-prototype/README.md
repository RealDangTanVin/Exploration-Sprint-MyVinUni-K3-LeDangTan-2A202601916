# 05 — Prototype

> Ghi chú AI: File khung này được tạo bằng AI (Command Code, 2026-10-15).

## Yêu cầu phần này
1. Prototype (code hoặc file nhấp/Figma export) giải quyết need statement trong [03-need-statement](../03-need-statement/).
2. **Prompt đã dùng** cho AI trong quá trình tạo prototype — lưu đầy đủ.
3. **Log thử với 2–3 người**: ai làm gì, vấp gì, nói gì.
4. **Ghi chú đã sửa gì** sau mỗi vòng feedback.

## Files trong thư mục này
- `prompt-*.md` — prompt đã dùng (1 file/vòng)
- `log-thu.md` — log thử với 2–3 người
- `ghi-chu-sua.md` — thay đổi sau mỗi vòng
- `code/` — mã nguồn prototype (nếu có)

## Phần nào do AI tạo
- [ ] File khung này: AI tạo.
- [ ] Prototype: ghi rõ công cụ + đã biên tập lại chỗ nào.
- [ ] Prompt template: AI hỗ trợ.
- Log thử: dữ liệu thật từ người dùng — không dùng AI tạo.
